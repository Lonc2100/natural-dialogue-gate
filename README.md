# 台词人话门禁

审查和修改中文影视对白，检查机械碎句、无效接话、功能性对白和采访式问答，让台词符合人物处境与表演目的。

## 安装
`npx skills add Lonc2100/natural-dialogue-gate --skill natural-dialogue-gate`

可将整个目录复制到兼容Agent Skills的客户端。普通ChatGPT上传资料不等于安装Skill。

## 使用示例
“使用 $natural-dialogue-gate，这段台词太碎，改得像人物真正说得出口的话。”
“只审查这段对白，最多指出三个影响表演的问题，并给可替换版本。”

输入：需要审核或修改的对白及必要人物、关系和时代信息。输出：用户指定范围的完整替换文本；仅审核时给少量问题和替换建议。不用于普通说明文、广告或只做翻译。

## 前提与排错
无额外CLI、API或联网依赖，需要能够理解中文影视文本的AI客户端。文件修改只在用户明确要求时执行。
删减标准用于判断，不能因为画面已出现或对白重复就机械删除；有意重复、回避、沉默前的承受及关系落点可能有表演价值。故意使用短句的角色应保留其声音。
